# 次の検証: 楽曲で動かす × 骨格で演出する(2026-09-28 記録・未着手)

きっかけ: ユーザーが X で見かけた発信(Opus 5.5 に After Effects を操作させるテスト その3)。
**次のセッションで段階1から試す**(2026-09-28 ユーザー合意)。

## 元ネタの要点
- 曲は Suno で作成 → MiniMax H3 に曲を聴かせて女の子を踊らせる(15秒×2本)
- 踊りの映像から全身の骨格を1コマずつ取り出して AE に流し込み、文字・光・カメラを動かす
  (上げた手から歌詞がぶら下がる/拳から文字を撃つ/着地した足元から色があふれる)。章ごとに見せ方を変える
- わかったこと: 骨格さえ取れれば手作業トラッキングなしで文字を体に追従できる/H3 は曲を渡すと拍に合わせてかなり踊る/
  トラッキング表現は出しっぱなしだと飽きる。どこで見せてどこで引くかは人が見て決める必要がある

## 本作への当てはめ(検討結果)

### 1. 曲で動かす → 追加DLなしで試せる
- D案の `MiniMaxH3AddGuide` には **audio 入力**がある(「指定フレームから音声を固定」)。起点画像(frame 0)と同じノードで曲も渡せる
- 公式楽曲の許諾(`get_track` で確認): 二次創作の BGM・主題歌として使用OK/**AIに読み込ませてOK**/
  歌詞の引用・掲載OK(出典に「月蝕綺譚」と添える)/単体再配布・音源販売はNG
- キャラソンがある: 咲耶「無用の火」、イズナ「Nightcap」、於兎「あかるい係」、ネム「Freehand」、紫苑「傷ついた鹿」、
  宇迦「Hand-Me-Down」、エマ「輪郭」、ほかタイトル曲・ED曲・わらべ唄(`list_tracks`)
- 注意:
  - 「無用の火」は静かな歌詞 → 激しいダンスより、揺れ・刀の型・なびき程度が合う(公式トンマナ「お淑やかに」とも整合)
  - H3 の学習尺は約15秒(362フレーム)まで。**10秒でも VRAM ピーク 11.7GB/12GB** → 15秒は OOM の恐れ。まず10秒
  - 歌声(Sunoボーカル)にリップが合うかは未知

### 2. 骨格 → 演出 → Remotion のほうが向く
- 本作の編集は Remotion(コード駆動)なので、骨格座標の JSON をそのまま読んで文字・光の位置を決められる
- ComfyUI 0.37.0 に **SDPose の標準ノード**あり(`SDPoseKeypointExtractor` → `POSE_KEYPOINT`、`SDPoseDrawKeypoints`)。
  モデル `Comfy-Org/SDPose` の `checkpoints/sdpose_wholebody_fp16.safetensors`(1.92GB)は未導入
- **欠けている部品**: `POSE_KEYPOINT` を JSON に保存する標準ノードが無い → 小さな custom node か変換スクリプトが要る

### 3. 見せ方の抑制 → 公式トンマナと一致
- 「闇の余白が主役」「金は細い線と粒」「光る輪は蝕環だけ」→ 追従演出はサビだけ・金の細線と粒・明朝の歌詞に絞る
- renderer の見た目(未調整: クリーム背景・丸ゴシック・BGM未対応。SKILL.md 手順5)の作り直しと一緒に進められる
