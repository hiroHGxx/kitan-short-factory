# 起点画像のChatGPT依頼プロンプト雛形

カットごとの起点画像(first_frame)を ChatGPT / Gemini 等の外部AIで生成してもらうときの
依頼文テンプレート。**参考画像2枚(`character/oen_base.jpg`=画風・キャラの基準、
`character/oen_standing.png`=立ち姿・等身の参考)を添付した上で**貼り付けてもらう。
立ち姿の服装(私服)に引っ張られないよう、依頼文に「2枚目は体型・ポーズの参考。
服装は各場面の指定に従う」の一文を入れる(ep006の依頼文参照)。
ep004_hoshifuru-yoru で実証済み(4カット全部一発OK・再生成ゼロ)。

## なぜカット別起点画像が必要か

H3はi2vのため**動画の1フレーム目=起点画像そのもの**になる。場面と合わない画像を
渡すと冒頭1〜2秒でディゾルブ変形し、制御不能な破綻(ep003の口から水しぶき等)の
遠因にもなる。カットの場面に合った画像を渡せばこの問題は起きない。

## 依頼文テンプレート

場面の数とその内容(【場面N】ブロック)だけ台本に合わせて差し替える。
【絶対に守ること】ブロックは実証済みの固定文なので変えない。

```
添付した画像のキャラクターと画風を完全に維持したまま、以下の{N}つの場面のイラストを1枚ずつ生成してください。

【絶対に守ること】
- 画風: 添付画像とまったく同じ、手描きの水彩アニメイラスト風。やわらかいパステルカラー、紙の質感、やさしい光。写実的にしない
- キャラクター: 添付画像と同一人物。顔立ち・髪型・髪色・体型を変えない
- 構図: 正方形(1:1)。キャラクターは画面中央付近、全身または膝上が写るサイズ
- 画像内に文字・ロゴ・透かしを入れない
- 各画像は動画の1フレーム目として使うので、動きの途中ではなく「静止した自然な姿勢」で描く

【場面1: {テロップ相当の場面名}】
{場面の説明。時間帯・場所・キャラの姿勢・光の様子を2〜3文で。h3_promptのSceneブロックの和訳でよい}

【場面2: ...】
...

まず場面1から順に、1枚ずつ生成してください。
```

## 運用メモ

- 出来た画像は `episodes/epNNN_{slug}/inputs/cut{N}_{slug}.png` の名前で保存してもらう
  (script.json の `input_image` がこの名前を参照する)
- 気に入らない場面は「場面2をもう一度、火をもっと小さく」のように個別リテイクしてもらう
- 服装はベース画像から変わっても構わない(ep004では着物に変わった)が、
  **全カット間で統一されていること**。h3_prompt の Scene ブロックには
  実際に生成された画像の服装・小道具を記述する
- 受け取ったら生成前にベース画像と見比べ、顔立ち・髪・特徴的パーツ(猫耳・メガネ等)の
  一貫性をチェックする
- **机・道具に向かうシーンは「正対」を明記する**(ep015で実証)。指定しないと
  机に対して横向きに座った構図になりがち。「ちゃぶ台に正対して座り、カメラは
  斜め前から顔が3/4見える角度」のように、体の向きとカメラ位置をセットで書く
- **実在の道具は使い方(機構)まで指定する**(ep015のかき氷機で実証)。
  「筒に氷のかたまり、削り氷は筒の真下の器に落ちる。器は必ず筒の真下」のように
  部品の位置関係を書かないと、機構的にありえない絵・動画になる。
  h3_prompt側のScene/Motionにも同じ機構説明を入れること
