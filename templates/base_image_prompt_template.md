# 起点画像の依頼プロンプト雛形(codex CLI / 月蝕綺譚)

カットごとの起点画像(first_frame)を codex CLI(内蔵 imagegen)で生成するための依頼文テンプレート。
**添付は各キャラの正典立ち絵+三面図シート**(`refs/{キャラ}/` から `inputs/` にコピーしたもの)。
正典シートは公式に「AIに読み込ませてOK」。他人の二次創作物は絶対に添付しない。
ep000_sakuya-engawa(1枚)・ep000_route-compare(3キャラ3枚を1セッション)で実証済み(全枚一発OK)。

## なぜカット別起点画像が必要か

標準経路(`generate.mjs --ref2v` = D案)では AddGuide で**動画の1フレーム目=起点画像**に固定する。
起点画像なしの Ref2VA(B案)だとトーンが言葉で制御できず、桜が淡いピンク・空が青くなる(docs/pipeline-design.md §6)。
起点画像が「宵闇に金」のトーンと構図を担い、正典シート参照がキャラの忠実度を、ボイス見本が声を担う分担。

## 実行方法

```
cd episodes/epNNN_{slug}
codex exec --skip-git-repo-check -s workspace-write \
  -i <絶対パス>/inputs/{キャラ}_canon.webp -i <絶対パス>/inputs/{キャラ}_sheet.webp \
  - < inputs/prompt_images.txt
```
- プロンプトは必ずファイル+stdin渡し(末尾の `-`)。`-i` が可変長引数で位置引数を吸い込むため
- **全カットを1セッションにまとめて依頼する**(分割するとトーン・服装が揃わない)。1枚約2分
- 複数キャラのときは添付順を依頼文に明記する(「1〜2枚目=餡音、3〜4枚目=イズナ…」)

## 依頼文テンプレート

【場面N】ブロックだけ台本に合わせて差し替える。【絶対に守ること】ブロックは実証済みの固定文なので変えない。

```
添付した画像のキャラクター({キャラ名}。1枚目が正典立ち絵、2枚目が三面図・表情シート)を完全に維持したまま、以下の{N}つの場面のイラストを1枚ずつ生成してください。

【絶対に守ること】
- 画風: 添付画像と同じ、すっきりした線画と淡い色のアニメ塗り(セル調)。写実的にしない
- キャラクター: 添付画像と同一人物。顔立ち・髪型・髪色・瞳の色・服装・持ち物を変えない。添付画像の背景(白・緑)は無視する
- 構図: 縦長(9:16)。キャラクターは画面中央付近、膝上が写るサイズ
- 世界のトーン: 藍黒の夜の闇が基調。金は細い線と小さな光の粒だけ(蒔絵のような品のある金)。桜は暗い紫の夜桜。明るい赤・白い背景・昼の光・祭りの提灯や屋台の雰囲気にしない
- 画像内に文字・ロゴ・透かしを入れない
- 動画の1フレーム目として使うので、動きの途中ではなく静止した自然な姿勢で描く
- 正典にない小物(団子・提灯・武器など)を足さない

【場面1: {テロップ相当の場面名}】→ inputs/cut1_{slug}.png
{場面の説明。時間帯・場所・キャラの姿勢と向き・光の様子を2〜3文で。Motion storyboard の開始状態と一致させる}

【場面2: ...】→ inputs/cut2_{slug}.png
...

【保存】
生成した画像は、このフォルダの上記のファイル名で保存してください(縦長9:16、941x1672相当)。全カット同じ世界観・同じ夜のトーンで揃えてください。
```

## 運用メモ

- 受け取ったら全枚を目視し、正典シートと見比べて顔立ち・髪・特徴的パーツ(狐耳・毛先の色・羽飾り・泣きぼくろ等)を確認する
- **画像の内容が台本とずれたら h3_prompt の Scene 側を画像に合わせる**(1フレーム目=起点画像のため)。
  ep000: 「淡い月に紅の縁」の指定が「黒く欠けた月蝕」で描かれたので Scene を直した
- 振り向いて話す台本なら、起点画像は「斜め向きで、顔はまだカメラを見ていない」と明記する
- 正典に描かれた持ち物(ナルカの羽扇など)は描いてよい。正典にない小物は動画で浮く・破綻する
- 以下は姉妹プロジェクト(i2v)での知見で、本作でも有効:
  - **机・道具に向かうシーンは「正対」を明記する**。体の向きとカメラ位置をセットで書く
  - **実在の道具は使い方(機構)まで指定する**。部品の位置関係を書かないと機構的にありえない絵になる。
    h3_prompt 側の Scene/Motion にも同じ機構説明を入れる
